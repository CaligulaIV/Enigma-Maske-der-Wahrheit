# The Mask of Truth – Werkzeuge für das Enigma

Online-Werkzeuge zum Pen&Paper-Regelwerk *The Mask of Truth*:

- **Schicksal** – Ja/Nein-Orakel (W100, 7 Wahrscheinlichkeiten), Tarot, Zufallsereignisse, Sitzungsprotokoll
- **Generatoren** – Wildnis, Gegner, Sammeln, Siedlungen, Ruinen, NPCs, Loot und mehr

Seite: https://caligulaiv.github.io/Enigma-Maske-der-Wahrheit/

Gespeichert wird im jeweiligen Browser. Mit „Sichern“ und „Laden“ lässt sich der Stand auf ein anderes Gerät übertragen.
